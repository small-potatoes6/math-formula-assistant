微信小程序《高中数学公式记忆助手》
功能计划书（头脑风暴版 v1）

定位高中生 / 高考复习党的碎片化记忆工具
一句话把高中三年数学的「基础公式」和「二级结论」装进口袋，按年级分块，用测试和遗忘曲线帮你真正记住，而不是收藏了就忘。

一、核心内容组织（内容架构）

内容是两层 × 三个年级的矩阵：

高一高二高三
基础公式 集合与逻辑、不等式、函数性质、指数对数、三角函数诱导公式、平面向量、复数 数列（等差等比通项/求和）、三角恒等变换、解三角形、立体几何（表面积体积、线面关系）、圆锥曲线基本定义、导数公式表 计数原理、二项式定理、概率分布（二项/超几何/正态）、统计、导数综合、圆锥曲线焦点弦等、圆锥曲线基本定义、导数公式表
二级结论 函数图像平移口诀、均值不等式"一正二定三相等"、向量投影速算等 等差等比性质链（m+n=p+q）、奇偶项求和技巧、焦点三角形面积、椭圆双曲线焦点弦结论、外接球八大模型等 排列组合"至多至少"转化、正态分布 3σ 原则、圆锥曲线第三定义、定比分点弦长公式、常见放缩不等式等
关键设计：每条二级结论必须带「推导或例题」。二级结论的价值在于理解来源，只背不用很快忘。每条结论配：① 原始推导（可折叠）② 一道典型例题 ③ 使用前提/易错点。

二、功能模块（头脑风暴清单）

模块 1：公式浏览（基础盘）

  • 「年级 → 科目章节 → 具体公式」三级导航，每条公式一张卡片。
  • 卡片正面：公式 + 适用条件；背面（点开）：文字解释、一个最小例子、易错提醒。
  • 全文搜索：输入"焦点弦""均值不等式"直接跳到对应公式。
  • 收藏夹：常看公式单独一栏，支持自定义分组（比如"考前 10 分钟必看"）。

模块 2：记忆训练（核心差异化，重点做）

  • 填空模式：公式卡片挖空关键处（如 sin(A+B) = sinA□□B + □…），让你填。
  • 选择题模式：给题目选正确公式 / 给公式选适用条件。
  • 默写模式：显示结论名称（如"椭圆焦点三角形面积公式"），自己默写后点击"显示答案"自评：会 / 模糊 / 不会。
  • 二级结论条件判断：这是易错重灾区。题目给出一个"看似能用结论"的题，判断这个结论能不能直接用（考察使用前提）。

模块 3：遗忘曲线复习（留存关键）

  • 每条公式记录你的掌握状态（会/模糊/不会 + 上次测试时间）。
  • 按艾宾浩斯间隔安排复习：1 天 → 3 天 → 7 天 → 15 天 → 30 天。
  • 首页每天显示「今日待复习 N 条」，点进去直接开测，3~5 分钟完成，符合碎片化场景。
  • 掌握度可视化：每个章节一个进度环 + 整体"记忆热力图"（哪些章节薄弱一眼看出）。

模块 4：错题与薄弱点

  • 测试答错的公式自动进错题本，可重测。
  • "薄弱章节"排行：按错误率排序，一键生成针对训练。

模块 5：轻社区 / 激励（后期可选）

  • 连续打卡天数、周报（"本周掌握了 23 条公式"）。
  • 公式背诵排行榜 / 好友对战（PK 模式：双人限时答题），微信生态里好友对战传播性强，但放二期。

模块 7：语音提问（听背模式）⭐ 新增

场景价值：走路、坐车、睡前这类「眼睛不方便看屏幕」的场景，是目前其他功能都覆盖不到的碎片时间。语音模式把可用时间再翻一倍。
  • AI 出声提问：进入「听背模式」后自动朗读问题，如"请问：椭圆的焦点三角形面积公式是什么？—— 5、4、3、2、1 —— 答案是：S = 2ab·sinθ / (a+b…)"，然后自动播下一条。全程免操作，像听播客一样过公式。
  • 技术方案：用微信官方免费插件「同声传译 WechatSI」，提供文字转语音（TTS）朗读和语音识别，无需自建服务器、零费用。题目文字本来就在公式库 JSON 里，直接转语音即可。
  • 交互设计：只问不判，自评打分：AI 提问 → 停顿（默认 10 秒，可调 10s / 20s / 30s / 不限时手动下一条）→ 倒数提示"3、2、1"（可关）→ 朗读标准答案 → 语音提示"请自评：会了请点 1，模糊点 2，不会点 3"（也可口头不评、跳过）。掌握状态由自评写入，与遗忘曲线复习打通。
    为什么不做语音作答比对：语音转文字对数学术语识别不可靠（"sinθ"易转错）、同义答案无法穷举比对，且机器判定常有假阳性；用户自评（Anki 同款思路）数据更真实。砍掉识别比对后，整个语音功能只剩「TTS 朗读 + 定时器」，零技术风险、零费用，可提前到二期上线。
  • 播报节奏：问题前短提示音（帮助集中注意力）；自评后 AI 给一句语音反馈（如"好，这条 7 天后再见"）补充仪式感。
  • 盲测模式（只提问、不给答案）：播报流程里跳过「朗读答案」环节，一条接一条连播。适用场景：考前快速自测、提取练习（大脑主动检索比看答案更能巩固记忆，有独立价值，不是阉割版）。配套细节：① 听的过程中可「标记本条」（点击按钮或语音说"标记"），标过的条目自动进错题本，明日待复习优先出现；② 播完一组后给一句总结（"本组 15 条，你标了 4 条"）。实现上只是播报开关差异，成本≈0。
  • 内容适配：语音模式只挑「文字友好」的条目提问（结论、条件、口诀类）；含分式/上下标的复杂公式念不出来，自动跳过或改为"报公式名称 → 你默想 → 报答案要点"。
  • 体验细节：倍速（0.8x/1x/1.2x）、锁屏后台继续播、耳机线控切上一条/下一条、支持只听「今日待复习」或指定章节。
  • 排期建议：技术门槛低（TTS 朗读 + 定时器 + 自评点击），随二期一起做，无需拖到三期。

模块 6：其他辅助

  • 深色模式、字号调节（公式多为图片/LaTeX 渲染，注意清晰度）。
  • 离线可用：公式内容本地缓存，没网也能背。

四、技术方案建议

  • 原生小程序 或 Taro/uni-app（如果以后想复用到 App/网页，选 uni-app）。
  • 公式渲染：推荐 LaTeX 渲染（如 knitroom / wxmath 类方案），或直接用高清 SVG/图片素材（更稳，开发快）。建议一期用预渲染图片，二期换 LaTeX。
  • 数据：公式库做成结构化 JSON（年级/章节/公式/推导/例题/易错点/标签），一期可打包进小程序本地，方便离线；用户数据（掌握状态、错题）用微信云开发（云数据库 + 云函数），免自建服务器，成本几乎为零。
  • 内容量预估：基础公式约 300~400 条，二级结论约 150~200 条，工作量主要在内容整理，程序本身不复杂。

五、开发节奏建议（分期）

MVP（一期，2~3 周）公式库浏览 + 收藏 + 搜索；填空/选择题测试；微信登录 + 掌握状态云端保存。先把"能查、能测"跑通。
二期（3~4 周）遗忘曲线复习计划 + 今日待复习；错题本；默写模式；掌握度统计图表。
三期（可选）好友 PK 对战、排行榜、打卡分享；二级结论社区投稿/纠错。

六、几个要想清楚的问题（我的观点）

1. 二级结论的"度"。很多老师反对死背二级结论。建议产品定位上明确：二级结论是"加速器"，必须先掌握对应基础公式才解锁记忆训练（比如背"焦点弦结论"前要先通过圆锥曲线基础公式的测试）——这个设计既科学又有产品特色。
2. 内容先行，程序其次。这个产品成败在内容质量：公式全不全、推导讲得清不清楚、易错点准不准。建议先花一周把高一的公式 JSON 整理出来当样板，再动工开发。
3. 差异化在哪。市面上公式查询 App 不少，但"按遗忘曲线主动推复习 + 二级结论带推导"这个组合不多。首页"今日待复习"应该是打开率的核心抓手。
4. 合规。小程序需要主体（个人或企业）认证；若面向未成年人注意隐私合规，不收集多余信息，一期可以完全匿名（不需要任何个人信息就能用）。
